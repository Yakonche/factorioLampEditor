## Factorio Lamp Editor 1.4.0

This release completes cross-platform font discovery, makes font and emoji
choices self-explanatory, and adds verified Linux portable packages.

Based on the original [Factorio Lamp Editor](https://github.com/jojkos/factorioLampEditor)
and its [web application](https://factorio-lamp-editor.vercel.app/).

### Highlights

- The desktop app now enumerates the complete font-family inventory reported
  by Windows, Linux, or macOS instead of checking a small curated list.
- Every font entry is rendered in its own typeface for an immediate preview.
- Bundled, system, and imported fonts remain separated into monospaced and
  proportional groups.
- Automatic emoji selection explicitly displays the detected renderer.
- Apple Color Emoji and Segoe UI Emoji are enabled only when actually detected,
  rather than inferred from the operating-system name.
- Bundled Noto Color Emoji is the guaranteed fallback when no native emoji
  renderer is available. The selected renderer also applies to animated emoji.
- Linux x64 packages now bundle a verified executable FFmpeg binary and are
  available as both an AppImage and a portable `tar.gz` archive.
