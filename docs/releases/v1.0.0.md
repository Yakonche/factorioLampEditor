## Factorio Lamp Editor 1.0.0

The first public release of the extended Factorio Lamp Editor fork.

Based on the original [Factorio Lamp Editor](https://github.com/jojkos/factorioLampEditor) and its [web application](https://factorio-lamp-editor.vercel.app/).

### Highlights

- Draw pixel art and generate Factorio 2.x lamp blueprints.
- Text stamps with global or per-character size, font, and color.
- Import TTF/OTF fonts and insert native or animated emoji.
- Resizable sidebar and bounded or scrolling text displays.
- Static images, multi-image slideshows, GIFs, and FFmpeg-readable videos.
- Proportional media resizing, frame selection, color modes, and delta filtering.
- Approximate stereo audio conversion to two programmable-speaker note sequences.
- Shared tick synchronization between linked audio and animations.
- Sparse animation ROMs, duplicate-frame merging, and Always ON static lamps.
- Real percentage progress during long blueprint generation.
- Configurable combinator placement, tiles, power poles, roboports, and help display.
