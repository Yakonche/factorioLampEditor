## Factorio Lamp Editor 1.1.0

This release expands text and emoji authoring, adds a complete French interface, and makes exceptionally large animation exports safer and easier to recover.

Based on the original [Factorio Lamp Editor](https://github.com/jojkos/factorioLampEditor) and its [web application](https://factorio-lamp-editor.vercel.app/).

### Highlights

- Complete Unicode RGI emoji catalog with search, categories, supported skin-tone variants, and lazy loading.
- Every catalog emoji can be converted to a Factorio blink, twinkle, or pulse animation.
- Stable animated-emoji layout inside proportional, monospaced, imported, and Japanese-font text.
- Built-in fonts grouped into monospaced and proportional families; imported TTF/OTF fonts are classified automatically.
- English/French interface switch with persistent language selection; Factorio item names stay in English.
- Real SVG language flags for consistent rendering on Windows.
- Resizable sidebar, per-character text styling, bounded display zones, and scrolling text.
- Static images, multi-image slideshows, complete GIF decoding, FFmpeg video, and proportional media resizing.
- Approximate stereo audio conversion to synchronized programmable-speaker note sequences.
- Sparse animation ROMs, duplicate-frame merging, static Always ON lamps, and real generation progress.
- Clear controller-infrastructure preview for combinators, substations, relays, speakers, and the optional display.
- Large-blueprint clipboard handling no longer performs a 100+ MB read-back. Failed copies clear stale clipboard data and can save the already-generated blueprint to a text file without repeating generation.
- Auto-place poles is enabled by default; the optional in-game timing/help display is disabled by default.

### Bad Apple validation

The bundled development fixture was validated at its original 360×270 resolution and 20 FPS: 3,118 sampled frames, 3,095 unique frames, and no definition or FPS reduction. A complete blueprint with synchronized approximate stereo notes generated successfully.
