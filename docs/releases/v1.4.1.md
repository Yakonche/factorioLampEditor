## Factorio Lamp Editor 1.4.1

This maintenance release fixes AppImage startup on current Kubuntu, Ubuntu,
and other Linux distributions that ship FUSE 3 instead of legacy FUSE 2.

Based on the original [Factorio Lamp Editor](https://github.com/jojkos/factorioLampEditor)
and its [web application](https://factorio-lamp-editor.vercel.app/).

### Fixed

- Replaced Electron Builder's legacy FUSE 2 AppImage toolset with its pinned
  static toolset `1.0.3`, which embeds AppImage runtime `20251108`.
- The AppImage no longer loads or requires `libfuse.so.2`, `libfuse2`, or
  `libfuse2t64` on the target computer.
- Current FUSE 3 installations, including current Kubuntu and Ubuntu releases,
  can mount the AppImage through their native `fusermount3` helper.
- Linux builds now fail validation if the generated AppImage references
  `libfuse.so.2`, uses an unexpected runtime, has an invalid SquashFS payload,
  or cannot extract its desktop entry.
- The portable `tar.gz` package remains available as a completely
  FUSE-independent alternative.

### Français

Cette version corrige le lancement de l’AppImage sur les versions actuelles de
Kubuntu, Ubuntu et les autres distributions qui fournissent FUSE 3 à la place
de l’ancien FUSE 2. Le nouveau runtime AppImage est statique et ne cherche plus
`libfuse.so.2` : il n’est donc plus nécessaire d’installer `libfuse2` ou
`libfuse2t64`.

Le système doit toujours disposer du périphérique `/dev/fuse` et de l’outil
`fusermount3`, normalement présents avec une installation FUSE 3 fonctionnelle.
L’archive portable `tar.gz` reste disponible comme solution indépendante de
FUSE.

See the [English README](https://github.com/Yakonche/factorioLampEditor#readme)
and [README français](https://github.com/Yakonche/factorioLampEditor/blob/main/README-FR.md)
for usage and build instructions.
